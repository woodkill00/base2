# Capacity and operations checkpoint

The versioned `small-preview` profile defines requests, soak rounds, queue depth, cache contention, p95 latency, error rate, and memory ceilings. Its local drill proves bounded backpressure, lossless queue drain, single-flight cache fill, soak stability, resource bounds, and data integrity.

The providerless operations checkpoint combines three encrypted backup/restore cycles, three verified immutable releases, incident deduplication/recovery, ACME staging renewal, and the capacity drill. Temporary state is removed and provider/resource/credential counters remain zero. Real load against public infrastructure and provider mutations require separate authorization.
