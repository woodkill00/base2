# Volcano authentication usability

Preserve the approved Obsidian/Volcano design on every application page and state.
Extend shared controls rather than replace the shell, menus or composition.

- R01: All existing password fields support accessible show/hide, hidden initially,
  without changing the value, submitting the form or persisting visibility/passwords.
- R02: Google sign-in uses the official filled_black theme, integrated into our
  existing layout. Google's external chooser and branding are not overridden.
- R03: Login/signup/reset retain validation, autofill, loading, recovery, nonce,
  redirect and session protections. Revealed passwords hide on field blur.
- R04: Shared consumers retain Volcano styling, responsive layout, keyboard access,
  reduced-motion behavior and light-preference compatibility.
- R05: Unit, browser, visual, coverage and complete-gate evidence precede release.
  Synthetic Google tests are not represented as real-provider visual acceptance.

No backend account linking, credential storage, new password-change endpoint,
provider permissions, paid trial or production TLS is authorized by this feature.
