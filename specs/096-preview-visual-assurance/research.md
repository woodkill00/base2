# Research and Decisions

## R1 - Exact-address verification remains necessary

Authoritative DNS can be correct while router or ISP recursive caches retain retired records. The accepted model is two independent gates: public DNS convergence evidence and exact leased-address application evidence.

## R2 - Runtime identity must precede credential access

An interactive WSL shell selected Windows npm and failed before Playwright execution. The control plane therefore checks resolved executable paths, ELF/Linux identity, architecture, and repository location before any SecretRef resolution or provider call.

## R3 - Expiry must be launch output, not a runbook reminder

An expired prior lease remained until explicit cleanup because no active timer was present. Every launch must produce and verify a persistent exact-run expiry plan. A missing watchdog is a failed closeout condition.

## R4 - Visual proof needs both deterministic baselines and live evidence

Repository snapshots catch regression, while live screenshots prove deployed composition, authentication, routing, fonts, and proxy behavior. Both are required and must bind to the same exact commit/profile.

## R5 - Responsive guarantees are contractual, not universal

No finite suite can prove every future browser/device. Base2 will guarantee declared width, height, orientation, DPR, zoom, font-scale, motion, input, and geometry contracts, then make expansion data-driven.

## R6 - SVG preference needs a classified exception model

Blanket rejection of raster assets would incorrectly reject photographs and screenshot evidence. UI artwork is SVG-required; raster usage must be located in an allowlisted content/evidence class with alt text or decorative semantics.
